# Repeated-CV paper figure bundle

Evaluation: stratified 5-fold outer CV repeated 3 times.
Inside each outer training fold, a stratified inner train/validation split is used. Standardization, PCA and angle scaling are fitted only on inner-training data. Circuit selection uses validation labels only; outer test labels are reserved for evaluation.
Performance-oriented GA and random search rank candidates by 0.5 × validation balanced accuracy + 0.5 × validation macro-F1. Complexity-aware GA and complexity-aware random search both select the least complex candidate within 0.02 absolute of the best observed inner-validation balanced accuracy, breaking ties by estimated depth, total gates and validation metrics. Each random-search baseline targets the same number of unique circuit evaluations as its paired GA within that outer fold; actual attempts, unique candidates and elapsed time are recorded separately.
Pooled repeated-CV confidence intervals use sample-cluster bootstrap resampling, retaining each sample's repeated predictions together. A supplemental Wilson interval is calculated from one majority-vote prediction per unique sample and has a different estimand, so do not conflate the two. paired_cluster_bootstrap_vs_logistic30.csv compares QML methods against full-feature logistic regression; paired_cluster_bootstrap_qml_vs_classical.csv compares each QML method against all eight classical baselines; paired_cluster_bootstrap_qml_methods.csv contains the pre-specified paired search-method contrasts. accuracy_constraint_audit.csv checks the constraint for both GA and random-search complexity-aware methods. Search runtime is local wall-clock time, not physical hardware runtime.
Quantum circuits are built with Qiskit QuantumCircuit and evaluated using Qiskit Statevector. There are no cloud jobs, device noise, transpiled hardware-cost measurements, or physical-QPU results.
Dataset: Wine (class 0 vs. classes 1/2). Binary task: wine cultivar class 0 (class 0) versus cultivars 1 and 2 (class 1). Class 0 is Wine class 0; class 1 is Wine classes 1/2.
This is a local benchmark study, not a clinical prediction system. Do not infer quantum advantage from these results. Repeated CV improves internal robustness but is not independent external validation.

## Figures

- `cv_fig1_balanced_accuracy_ci.pdf` / `.png`: Figure 1. Balanced accuracy measured on pooled outer-fold predictions from repeated stratified five-fold cross-validation. Error bars show 95% sample-cluster bootstrap confidence intervals that keep repeated predictions for each sample together.
- `cv_fig2_classification_metrics.pdf` / `.png`: Figure 2. Balanced accuracy, macro-F1, and recall for class 0 (Wine class 0) on repeated outer-fold predictions for Wine (class 0 vs. classes 1/2). Error bars are 95% sample-cluster bootstrap confidence intervals.
- `cv_fig3_evolution_fold_stability.pdf` / `.png`: Figure 3. Fold-level held-out balanced accuracy for two evolutionary objectives and their candidate-budget-matched random-search controls. Each point represents one outer test partition; test labels are used only for evaluation, not for circuit selection.
- `cv_fig4_accuracy_complexity_tradeoff.pdf` / `.png`: Figure 4. Outer-fold balanced accuracy versus logical circuit depth for evolved and random-search circuits. Circle size is proportional to the number of two-qubit gates; diamonds show method means. These are logical circuit metrics, not transpiled hardware cost or measured hardware performance.
- `cv_fig5_validation_vs_outer_test.pdf` / `.png`: Figure 5. Inner validation balanced accuracy versus held-out outer-test balanced accuracy for evolved and random-search circuits. The plot diagnoses selection optimism; the outer-test values were not used to choose the circuit.
- `cv_fig6_confusion_matrices.pdf` / `.png`: Figure 6. Row-normalized confusion matrices pooled over out-of-fold predictions from all repeats for two pre-specified reference models: full-feature logistic regression and the complexity-aware evolved QML circuit. Values are benchmark results, not clinical validation.
- `cv_fig7_paired_difference_vs_classical.pdf` / `.png`: Figure 7. Paired sample-cluster bootstrap differences in outer-fold balanced accuracy relative to full-feature logistic regression. Intervals crossing zero do not establish a difference at the corresponding nominal confidence level; repeated-CV observations are clustered by sample.
- `cv_fig8_pca_variance_stability.pdf` / `.png`: Figure 8. Mean variance explained by each of the four PCA components across inner-training partitions, with fold-to-fold standard deviations. These components are fitted independently within each fold to avoid test-data leakage.
