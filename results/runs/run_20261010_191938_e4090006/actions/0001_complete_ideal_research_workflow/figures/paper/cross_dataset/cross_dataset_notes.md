Cross-dataset balanced-accuracy comparison. Error bars are per-dataset sample-cluster bootstrap 95% confidence intervals. The constrained random-search baseline uses the same balanced-accuracy tolerance and complexity tie-breaks as the complexity-aware GA and is matched by unique candidate evaluations within fold. The 6 tasks are not pooled into a single score because they have different samples, features and target definitions. All tasks use the same four-qubit local Qiskit statevector simulator; no QPU or hardware-noise results are included.
